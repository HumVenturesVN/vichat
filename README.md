# Tự cân liều vi chất

Công cụ tự cộng liều vi chất cho đội ngũ HumVentures: https://vichat.humventures.vn

Trang tĩnh, chạy trên GitHub Pages. Số người dùng nhập chỉ lưu trên trình duyệt của họ (localStorage và cookie), không có máy chủ thu thập.

- `index.html`: toàn bộ trang
- `assets/`: logo, favicon (lấy từ thư mục Logo chính thức trên SharePoint HumVietnam)
- `CNAME`: tên miền riêng
